Select
	A.[Country] As [Country],
	A.[First_Field] As [First_Field],
	A.[Second_Field] As [Second_Field],
	(Case When B.[Country] Is Not Null Then B.[Geo_1] Else (Case When C.[Country] Is Not Null Then C.[Geo_1] Else (Case When D.[Country] Is Not Null Then D.[Geo_1] Else E.[Geo_1] End) End) End) As [Geo_1],
	(Case When B.[Country] Is Not Null Then B.[Geo_2] Else (Case When C.[Country] Is Not Null Then C.[Geo_2] Else (Case When D.[Country] Is Not Null Then D.[Geo_2] Else E.[Geo_2] End) End) End) As [Geo_2],
	(Case When B.[Country] Is Not Null Then B.[Geo_3] Else (Case When C.[Country] Is Not Null Then C.[Geo_3] Else (Case When D.[Country] Is Not Null Then D.[Geo_3] Else E.[Geo_3] End) End) End) As [Geo_3]
From @Large_Data_Input_Table A
Left Join @Large_Match_Table B
	On (B.[Country] = A.[Country] And A.[First_Field] = (Cast(A.[Country] As Varchar(Max)) + 'ZZZ') And B.[Geocode] = A.[First_Field])
Left Join @Large_Match_Table C
	On (C.[Country] = A.[Country] And C.[Geocode] = A.[First_Field] Or C.[Country] = A.[Country] And C.[Geocode] = A.[Second_Field])
Left Join @Large_Match_Table D
	On (D.[Country] = A.[Country] And D.[Geocode] = Left(A.[Second_Field], 3))
Left Join @Large_Match_Table E
	On (B.[Country] = A.[Country] And B.[Geocode] = Left(A.[Second_Field], 2))
