--Summary Comment: This T-SQL script contains algorithms that can be used to design a very efficient storage space, and network transmission, string data format, for table/matrix/grid data structures... The Obsidian Compound Object String data format, is ultimately, a very size efficient storage option. The downside is that it would typically lead to more compute demand when later used (due to the need to unwrap the string into a grid), and as a direct consequence, is less suited to latency sensitive usecases.

					End
				Else If Patindex(('%' + @Benchmark_Row_Delimiter_String_Pattern + '%'), @Benchmark_Input_String_Slider) < Patindex(('%' + @Benchmark_Cell_Delimiter_String_Pattern + '%'), @Benchmark_Input_String_Slider)

					End
	
			End
	End
